>[!example]+ **潜龙在渊**
>- **类型：主图**
>- **代码**
>```
>{--- 均线核心参数 ---}
MA5:=MA(CLOSE,5);
MA10:MA(CLOSE,10);
MA18:=MA(CLOSE,18);
MA30:=MA(CLOSE,30);
MA90:=MA(CLOSE,90);
>
{--- 趋势 ---}
{ K类似物理学中的加速度概念 }
K:=round2(CLOSE/REF(CLOSE,1),2);  {斜率}
上升:=K>REF(K,1);
降速:=K-REF(K,1) < REF(K,1)-REF(K,2) and REF(K,2)-REF(K,3) < REF(K,1)-REF(K,2);
减速:=REF(K,1) > 0 and K < 0;
拐点:=K/REF(K,1) < 0;
>
{--- 成交量 ---}
缩量:=VOL < MA(VOL,5)*0.8;
放量:=VOL > REF(VOL,1) and VOL < REF(VOL,1)*2;
倍量:=VOL > REF(VOL,1)*2;
天量:=VOL > REF(VOL,1)*3;
探底:=LOW < MA18 AND CLOSE > MA18;
>
{--- K线特征 ---}
阳线:=CLOSE > OPEN;
阴线:=CLOSE < OPEN;
实体:=Max(OPEN,CLOSE) - Min(OPEN,CLOSE);
上影:=(H - max(OPEN,CLOSE)); 
下影:=(MIN(OPEN,CLOSE) - LOW); 
>
{-------- 位置 ---------}
>
{--- 信号 ---}
金叉趋势:= Ma5-Ma10<0 and Ma5>REF(MA5,1);
金针探底:=探底 and 下影/实体 >= 2;
射击之星:=上影>=实体*2 And 阴线 and 
晨曦之星:=
创新高:=CLOSE=hhv(high,20);
创新低:=CLOSE=llv(low,20);
MACD顶背离:=
>
{--- 提示 ---}
Drawtext(,,)
>
{画一条20日均线方便看盘}
MA5日均线:MA5,COLORRED,LINETHICK2;
ma10日均线:M10,colorlired,linethicK2;
MA18日均线:MA18,COLORYELLOW,LINETHICK1;
>```
>- 注: </br>潜龙在渊（就是你之前看的那个版本）的雏形，后来嫌不好拼接识别所以放弃了。



>[!example]+ **趋势延续性(不吃鱼尾) **
>- **类型：副图**
>- **代码**
>```
>{主力筹码估算}
ZLCM:=EMA(WINNER(C)*70,3);
SHCM:=EMA((WINNER(C*1.1)-WINNER(C*0.9))*80,3);
>
{主力控盘度}
控盘:=ZLCM-SHCM;
控盘比例:=控盘/LLV(控盘,100)*100;
>
{资金流向}
ZJ11:=(2*C+H+L+O)/5;
ZJ12:=EMA(EMA(EMA(ZJ11,4),4),4);
资金流向:=(ZJ12-REF(ZJ12,1))/REF(ZJ12,1)*100;
>
{主力活跃度}
主力活跃:=V/MA(V,20)*100;
>
{可视化}
STICKLINE(控盘比例>REF(控盘比例,1) AND 控盘比例>0,0,控盘比例,2,0),COLORLIBLUE;
STICKLINE(控盘比例<REF(控盘比例,1) AND 控盘比例>0,0,控盘比例,2,0),COLORLIRED;
STICKLINE(控盘比例<0,0,控盘比例,2,0),COLORLIGREEN;
>
{信号线}
安全线:20,COLORLIGREEN,DOTLINE;
风险线:80,COLORRED,DOTLINE;
>
{金叉信号}
DRAWTEXT(CROSS(控盘比例,安全线) AND 资金流向>0,1,'^'),COLORYELLOW;
DRAWICON(CROSS(控盘比例,安全线) AND 资金流向>0,10,1);
>
>```
>- **体感：**</br>连续趋势（起码3-4根）的粉柱代表持续上涨，如果粉柱变蓝大概率要转跌了，直接跑（有余量）



> [!example]+ 量价
> - **类型：副图**
> - **代码**
>```
> {===== 统计量化副图 =====}
{适用：日线，副图}
{信号：收敛 + 脱钩 → 共振}
>
{----- 线性回归 -----}
回归值 := FORCAST(C, 20);
斜率 := SLOPE(C, 20);
偏离度 := (C - 回归值) / 回归值 * 100;
>
{----- 波动率 -----}
波动值 := STD(C, 10);
波动基准 := MA(波动值, 20);
>
{----- 相关性 -----}
相关系数 := RELATE(C, INDEXC, 20);
>
{===== 绘制 =====}
回归线: 回归值, COLORWHITE, LINETHICK1;
收盘价: C, COLOR-YELLOW, LINETHICK1;
>
{偏离柱}
STICKLINE(偏离度>0, 0, 偏离度, 2, 0), COLORRED;
STICKLINE(偏离度<0, 0, 偏离度, 2, 0), COLORGREEN;
>
{波动线}
波动线: 波动值 * 2, COLORLIGRAY, LINETHICK1;
波动参考: 波动基准, COLORGRAY, LINETHICK2;
>
DRAWTEXT(波动值 < 波动基准 * 0.55, 3, '$'), COLORGREEN;
DRAWTEXT(波动值 > 波动基准 * 2.25, -3, '!'), COLORRED;
>
{相关线}
相关线: 相关系数 * 5, COLORMAGENTA, LINETHICK1;
>
DRAWTEXT(相关系数 <  MA(相关系数,3)*0.50, 5, 'V'), COLORYELLOW;
>
{----- 共振信号 -----}
趋势健康 := 偏离度 > -5 AND 偏离度 < 5;
波动收敛 := 波动值 < 波动基准 * 0.55;
脱钩确认 := 相关系数 < 0.5;
>
强共振 := 趋势健康 AND 波动收敛 AND 脱钩确认;
DRAWTEXT(强共振, 偏离度*0.98, '★'), COLORRED;
>
{===== 数值面板（修正 DRAWNUMBER_FIX） =====}
DRAWTEXT_FIX(ISLASTBAR, 0.78, 0.08, 0, '斜率:'), COLORWHITE;
DRAWNUMBER_FIX(ISLASTBAR, 0.83, 0.08, 0, ROUND2(斜率, 2));
>
DRAWTEXT_FIX(ISLASTBAR, 0.88, 0.08, 0, '偏离:'), COLORWHITE;
DRAWNUMBER_FIX(ISLASTBAR, 0.93, 0.08, 0, ROUND2(偏离度, 1));
>
DRAWTEXT_FIX(ISLASTBAR, 0.78, 0.32, 0, '波动:'), COLORWHITE;
DRAWNUMBER_FIX(ISLASTBAR, 0.83, 0.32, 0, ROUND2(波动值, 2));
>
DRAWTEXT_FIX(ISLASTBAR, 0.88, 0.32, 0, '相关:'), COLORWHITE;
DRAWNUMBER_FIX(ISLASTBAR, 0.93, 0.32, 0, ROUND2(相关系数, 2));
>```
>
