## Dataview 双维度检索速查

### 1. 按部件检索（例：找所有"液冷"相关笔记）
```dataview
TABLE Raw-Material, Area, Confidence
FROM "贰 • 杂学"
WHERE contains(Component, "液冷")
```

### 2. 按原材料检索（例：找所有涉及"铋"的笔记，跨行业聚合）
```dataview
TABLE Component, Area
FROM "贰 • 杂学"
WHERE contains(Raw-Material, "铋")
```

### 3. 双维度联合（例：部件=光刻 且 原材料含 光刻胶）
```dataview
LIST FROM "贰 • 杂学"
WHERE contains(Component, "光刻") AND contains(Raw-Material, "光刻胶")
```

### 4. GROUP BY 出全库材料索引（平铺所有出现过的原材料）
```dataview
TABLE file.link AS 笔记, Component
FROM "贰 • 杂学"
FLATTEN Raw-Material AS 原材料
WHERE 原材料
SORT 原材料
```

## 关键约定
- Component / Raw-Material 必须是 **YAML 数组**（`- 值` 形式），Dataview 的 contains() 才能正确匹配。
- 一篇笔记可同时属多个部件、多个原材料，不用为此建子文件夹。
- 行业大类仍用文件夹（如 `贰 • 杂学/07 半导体/`），文件夹下不再细分材料/部件。
