# 半导体材料九大类

> [!note] 来源说明
> 本文件整合自公众号"发现下一片绿洲"《半导体材料 九大类及企业》信息图。

## 一、光刻胶

光刻工艺核心感光材料，决定芯片制程节点，分为 G/I 线 KrF、ArF、EUV 光刻胶。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 彤程新材、南大光电、上海新阳、华软科技、晶瑞电材、容大感光、飞凯材料等 |
| 国际 | JSR、东京应化、信越化学、住友化学、默克（原Dow）、富士胶片、LG化学等 |

> [!tip] 关联
> 光刻胶与 [[氟化工产业链]] 的含氟光刻胶同属上游材料体系。

## 二、电子特气

电子特种气体参与刻蚀、掺杂、沉积等环节并发挥作用。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 华特气体、金宏气体、南大光电、雅克科技、昊华科技、和远气体、派瑞股份等 |
| 国际 | 空气化工、林德集团、大阳日酸、法国液空、昭和电工等 |

> [!tip] 关联
> 详见 [[六氟化钨]]（电子特气细分）、[[氟化工产业链]]

## 三、硅片（晶圆衬底）

> [!tip] 深度分析
> 12英寸硅片详见 → [[12英寸硅片产业链]]

芯片制造的物理基底，占晶圆制造材料总成本的 **30-40%**，是半导体材料中市场份额 Top 级品类。核心分为 8 英寸（成熟制程及特色工艺）和 12 英寸（先进制程）硅片。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 沪硅产业、立昂微、TCL中环、有研硅、上海合晶、神工股份、中晶科技、中欣晶圆 |
| 国际 | 信越化学、SUMCO、环球晶圆、SK Siltron |

## 四、光掩模版

光掩模版是半导体光刻工艺中的核心材料，直接决定了芯片电路图案的精度。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 路维光电、清溢光电、龙图光罩、迪思微（华润微旗下）、中微掩膜、中芯国际（自研自用） |
| 国际 | Toppan、DNP、Photronics |

## 五、湿电子化学品

芯片制造用高纯试剂，用于清洗、刻蚀、显影等环节，分为通用试剂和功能性试剂。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 晶瑞电材、江化微、上海新阳、强力新材、中巨芯、格林达、多氟多 |
| 国际 | 巴斯夫、默克、三菱化学、关东化学、Stella Chemifa |

> [!tip] 关联
> 详见 [[半导体关键材料综合]]（含电子级硫酸）、[[氟化工产业链]]（含电子级氢氟酸）

## 六、CMP 抛光材料

晶圆纳米级平坦化核心材料，分为抛光液和抛光垫两大核心品类，是先进制程多层布线的关键材料。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 安集科技、鼎龙股份、博来纳润 |
| 国际 | 卡博特/Cabot、杜邦、日立化成 |

### 品类功能

| 品类 | 功能作用 |
|------|----------|
| 抛光液 | 提供化学反应介质（氧化剂、腐蚀剂）和研磨颗粒（SiO₂、Al₂O₃、CeO₂等），实现选择性去除 |
| 抛光垫 | 提供机械研磨平台，储存和传输抛光液，控制去除均匀性 |

## 七、溅射靶材

物理气相沉积（PVD）工艺的关键耗材，通过高能离子轰击靶材表面，使原子逸出并沉积在晶圆上形成薄膜，用于制备金属互连、阻挡层、粘附层等。

| 类别 | 代表企业 |
|------|----------|
| 国内 | 江丰电子、有研新材（有研亿金） |
| 国际 | 日矿金属、霍尼韦尔 |

## 八、芯片封装材料

芯片封装材料主要包括封装基板（IC载板）、环氧塑封料（EMC）、键合材料、先进封装配套材料、引线框架。

| 品类 | 国内企业 |
|------|----------|
| 封装基板（IC载板） | 深南电路、兴森科技、胜宏科技 |
| 环氧塑封料（EMC） | 华海诚科、德邦科技 |
| 键合材料 | 帝科股份、聚和材料 |
| 先进封装配套材料 | 联瑞新材、华海诚科 |
| 引线框架 | 康强电子、华洋电子 |

> [!tip] 关联
> 详见 [[封装与载板材料]]

## 九、第三代半导体衬底材料

宽禁带半导体材料，面向功率器件、射频器件、光电器件，在新能源、汽车电子、5G 通信、航天航空领域占据核心基础地位。

| 材料品类 | 部分相关企业 |
|----------|-------------|
| 碳化硅（SiC） | 天岳先进、三安光电、天科合达、烁科晶体、东尼电子 |
| 氮化镓（GaN） | 三安光电、英诺赛科、海特高新、耐威科技 |
| 氧化镓（Ga₂O₃）/金刚石衬底 | 铭镓半导体、中电科55所、化合积电 |

> 详见 [[碳基材料]]

## IMA 补充内容（2026-06-21）

### 半导体核心材料：磷化铟、电子布、铜箔、电子级硫酸

> [!note] 来源
> 《半导体核心材料：磷化铟、电子布、铜箔、电子级硫酸及龙头公司介绍》（2026-06-18）

#### 四大材料定位

| 材料 | 产业链位置 | 利润逻辑 |
|------|------------|----------|
| **磷化铟** | 光芯片"地基" | 技术垄断溢价，6英寸大尺寸产能稀缺 |
| **电子布** | PCB板的"骨架" | 高端产品结构性溢价 |
| **电子铜箔** | PCB导电层 | 加工费模式，高端高频高速铜箔加工费更高 |
| **电子级硫酸** | 晶圆制造的"血液" | 纯度溢价与废酸回收 |

#### 磷化铟（InP）

| 项目 | 说明 |
|------|------|
| 用途 | 高速光模块（800G/1.6T）核心光芯片 |
| 利润逻辑 | 单晶生长技术壁垒极高，6英寸大尺寸产能稀缺 |
| 市场 | AI算力基础设施关键材料 |

#### 电子布（电子级玻纤布）

| 项目 | 说明 |
|------|------|
| 组成 | 玻璃纤维纱编织而成 |
| 用途 | 覆铜板（CCL）和印制电路板（PCB）的核心增强材料 |
| 利润逻辑 | AI服务器推动PCB层数增加，对极薄、低损耗电子布需求激增 |
| 代表企业 | 中国巨石、宏和科技 |

#### 电子铜箔

| 项目 | 说明 |
|------|------|
| 分类 | 电子电路铜箔（PCB）、锂电铜箔（电池） |
| 利润逻辑 | 成本受铜价影响大，利润来自"加工费"减去制造成本 |
| 高端产品 | 高频高速铜箔（用于服务器）加工费更高 |
| 代表企业 | 嘉元科技、中一科技、铜冠铜箔 |

#### 电子级硫酸

| 项目 | 说明 |
|------|------|
| 用途 | 晶圆制造中的清洗和蚀刻环节 |
| 纯度要求 | G4/G5级（金属杂质≤1ppt） |
| 利润逻辑 | G5级提纯技术壁垒高；头部企业通过废酸回收大幅降低成本 |
| 代表企业 | 多氟多、晶瑞电材 |

#### 风险提示

| 材料 | 风险 |
|------|------|
| 磷化铟 | 受铟价波动影响大 |
| 电子布/铜箔 | 存在周期性产能过剩风险 |
| 电子级硫酸 | 运输半径短，依赖晶圆厂集群布局 |
