# 液冷服务器板块梳理

> 来源：公开信息整理
> VL72单机柜液冷价值量约10万美元，随着GB200/300高密度功率机柜出货放量，AI数据中心液冷渗透率有望从B200~10%提升至GB300~90%，预计25年或为液冷起量元年，26年液冷业绩陡增

## 液冷服务器

| 公司 | 核心看点 |
|------|---------|
| **英维克** | 已推出针对算力设备和数据中心的Coolinside液冷机柜及全链条液冷解决方案 |
| **浪潮信息** | 将"All in 液冷"纳入发展战略，全栈布局并发布液冷产品，实现通用服务器、高密度服务器、整机柜服务器、AI服务器四大系列 |
| **中科曙光** | 拥有ParaStor液冷存储产品与液冷服务器，并以此形成"存算一站式"液冷方案 |
| **中兴通讯** | 拥有全系列服务器及存储产品，包括通用、GPU、液冷服务器以及全闪、混闪存储产品等 |
| **紫光股份** | 发布了H3CUniServer R4900LCG5液冷服务器 |

## 液冷产品

| 公司 | 核心看点 |
|------|---------|
| **大元泵业** | 公司相关液冷产品进入华为中兴测试阶段 |
| **康盛股份** | 液冷机房产品已应用到新华三服务器 |
| **川润股份** | 在数据中心、云计算、IDC、通信网络等人工智能应用方面有液冷和温控技术及产品储备 |
| **硕贝德** | 布局有液冷散热产品，可应用于服务器路由器交换机（GPU/CPU冷却），及光伏储能新能源汽车等领域 |
| **高澜股份** | 服务器液冷业务拥有三种解决方案：冷板式液冷、浸没式液冷和集装箱式液冷，可有效降低大型数据中心的PUE |
| **网宿科技** | 全资子公司绿色云图自主研发的浸没式液冷技术，能够为企业提供更节能、高效的液冷数据中心建设及改造方案 |
| **申菱环境** | 拥有新一代温控产品如DPC相变冷却系统、新型高效蒸发冷却系统、液冷温控系统等 |
| **光迅科技** | 是浸没液冷智算产业发展联盟会员单位，是相关标准、工艺研究和实践的重要参与者之一 |
| **神州数码** | 2024年5月官网发布全新智算架构和液冷整机柜产品，应对"多云、异构、绿色"挑战 |
| **科士达** | 2024年1月互动易：数据中心温控产品已有液冷技术和产品 |
| **烽火通信** | 全新一代FitNeo LCS液冷解决方案，专为高热密度机柜绿色低碳运营而设计 |
| **润泽科技** | 已经开始批量交付液冷机柜，正在交付的以10kw左右的高密机柜为主，以及20kw以上的液冷机柜 |
| **统一股份** | 推出了数据中心专属液冷产品组合解决方案，相关产品包括低电导率热管理液NE100等 |
| **同星科技** | 液冷相关产品有应用于数据中心及液冷服务器 |
| **飞龙股份** | 数据中心液冷产品在芜湖飞龙、郑州飞龙已建有专门生产线 |
