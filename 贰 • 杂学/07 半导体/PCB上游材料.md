# PCB上游材料

> [!note] 概述
> PCB（印制电路板）上游材料按三级产业链划分，核心是覆铜板（CCL），其上游为铜箔、电子玻纤布、电子树脂三大主材。AI驱动高端材料需求爆发，供需缺口持续扩大。

## 产业链三级结构

```
最上游：基础原材料（成本占比20-30%）
├── 金属原料 → 电解铜（纯度≥99.999%）
├── 无机材料 → 电子级玻纤纱（E-glass、D-glass、S-glass）
└── 化工原料 → 双酚A、环氧氯丙烷、苯乙烯、苯酚等
    ↓
上游核心主材（成本占比约50-70%）
├── 铜箔（电解/压延）
├── 电子玻纤布
└── 电子树脂（环氧、酚醛、碳氢、PPE等）
    ↓
中游覆铜板（CCL）
├── 刚性 CCL（FR-4、高频高速CCL）
└── 柔性 CCL（FPC用）
    ↓
下游 PCB 制造
```

## 投资建议

> [!important] 优先布局
> **高频高速CCL**（生益科技、南亚新材）和**载体铜箔**（德福科技）——兼具技术壁垒高+需求爆发+国产替代三重逻辑，利润率可达**30-50%**。

> [!note] 重点关注
> **低介电电子布**（宏和科技）和**高端树脂**（东材科技）——国产化率提升空间大，2027年预计达40%+。

> [!warning] 规避领域
> 普通FR-4、标准铜箔等低端材料，竞争激烈，利润率仅5-10%，易受价格战影响。
