# 电子布与电子铜箔（PCB 基础材料）

> [!note] 来源
> 《半导体核心材料：磷化铟、电子布、铜箔、电子级硫酸及龙头公司介绍》（2026-06-18）提炼

## 电子布（电子级玻纤布）：PCB 的"骨架"

**定义**：由玻璃纤维纱编织而成，是覆铜板（CCL）和印制电路板（PCB）的核心增强材料

**利润逻辑**：高端产品结构性溢价
- AI 服务器推动 PCB 层数增加
- 对极薄、低损耗电子布需求激增
- 普通厚布利润较薄

**代表企业**：
- 中国巨石 — 电子玻纤布龙头
- 宏和科技 — 极薄电子布

## 电子铜箔：PCB 导电层与电池负极

**分类**：
- **电子电路铜箔**：用于 PCB
- **锂电铜箔**：用于电池

**利润逻辑**：加工费模式
- 铜箔成本受铜价影响大
- 利润主要来自"加工费"减去制造成本
- 高端高频高速铜箔（用于服务器）加工费更高

**代表企业**：嘉元科技、中一科技、铜冠铜箔

## 产业链关联

```
玻纤（中国巨石）→ 电子布 → 覆铜板(CCL) → PCB
电解铜 → 电子铜箔 → 覆铜板(CCL) → PCB
```
