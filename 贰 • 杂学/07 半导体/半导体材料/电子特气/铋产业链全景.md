# 铋产业链全景

> [!note] 来源说明
> 本文件整合自微信公众号文章《全球战略关键金属铋：地缘政治与产业基本面的双重范式转折》（2026-06-24发布）。

## 一、发生了什么？

### 1.1 出口管制：断供即将到来

- **2025年2月4日**：商务部、海关总署**2025年第10号公告**，将钨、碲、铋、钼、铟相关物项正式纳入两用物项出口管制（铋管制起点）。
- **2026年1月5日**：商务部、海关总署公布2026年度《两用物项和技术进出口许可证管理目录》，延续并调整管制范围。
- **2026年1月6日**：商务部**2026年第1号公告**，加强对日本两用物项出口管制（铋、钨等对日供给进一步收紧）。
- **2026年6月15日**：《矿产资源法实施条例》施行，稀土、镓、锗、铋等敏感品种出口审查趋严。

> [!note] 校验记录（2026-08-09 文献印证）
> 上述政策时间线已与商务部/海关总署公开公告交叉核对：2025年第10号公告（2025-02-04）、2026年目录（2026-01-05）、2026年第1号对日公告（2026-01-06）均属实。原稿将"2026年1月1日目录施行"误作管制起点，实为 **2025年2月已首纳管制**，本次已更正。出口量数据（2024→3797吨、2025→714吨、降81%、对日63吨）多源吻合，置信度高。

### 1.2 出口数据断崖式下跌

| 年份 | 精铋出口量 | 出口均价 | 对日出口 | 备注 |
|------|-----------|---------|----------|------|
| 2024（管制前） | 3,797吨 | 9.2万/吨 | 1,948吨 | 管制前正常水平 |
| 2025（管制首年） | **714吨** | — | **63吨** | 出口量暴跌超80% |
| 2026年1-4月 | 310吨 | — | — | 海关执法力度加强，跨境电商"蚂蚁搬家"违规集中爆发 |

> [!tip] 关键对比
> 三氧化二铋出口反而增长：2024年8,500吨 → 2025年9,267吨。管制主要针对高纯精铋。

### 1.3 日本TEC厂商库存即将耗尽

| 企业 | 全球碲化铋份额 | 库存耗尽时间 | 状态 |
|------|--------------|-------------|------|
| **泰戈+热磁** | **60%** | **6月底** | 已停止接受800G/1.6T光模块用TEC新订单 |
| **小松** | **20%** | **7月中旬** | 高端原料50%+从中国进口 |

> [!danger] 供应链断裂风险
> 三家合计占全球碲化铋市场 **80%**，停产将直接冲击 **800G/1.6T光模块TEC** 供应链。碲化铋是室温热电制冷的唯一成熟材料，**短期无替代方案**。

## 二、为什么重要？涨价或复刻六氟化钨

### 2.1 与六氟化钨的涨价逻辑对比

| 维度 | 六氟化钨 | 铋 |
|------|---------|-----|
| 中国主导上游 | 是（~80%） | **是（>85%产量）** |
| 出口管制触发 | 是 | 是 |
| 下游不可替代 | 是（3D NAND） | 是（TEC/光模块/半导体） |
| 价格起点 | 12万/吨 | 7.5万/吨 |
| 当前价格 | ~200万/吨 | **14.6万/吨** |
| 涨幅 | **~15倍** | **~1倍** |
| 供给弹性 | 低 | **极低（伴生矿，无法独立扩产）** |

> [!important] 核心判断
> 铋的供给弹性**远低于**六氟化钨——全球90%以上铋都是铅锌钨锡冶炼的伴生副产品，几乎无独立精铋矿。即使铋价暴涨1000%，也无法促使矿山单独为铋扩产。

### 2.2 当前价格（2026年6月）

| 产品 | 均价 |
|------|------|
| 精铋（Bi≥99.99%） | **146,000元/吨** |
| 4N 三氧化二铋 | 157,000元/吨 |
| 5N 三氧化二铋 | **350,000元/吨** |

价格从2024年底7.5万→2026年6月14.6万，**涨幅超100%**，创十年新高。

### 2.3 四重驱动力

```
驱动力一：出口管制 → 海外供给缺口 → 国内外价差拉大 → 推升国内价格
驱动力二：原料供应紧张 → 5月精炼铋产量环比-17% → 铅锌品位下降+环保趋严
驱动力三：新兴需求爆发 → 半导体领域铋需求同比+35%（2025） → TEC/光伏焊带/核反应堆
驱动力四：市场情绪 → 冶炼厂招标价上移 → 贸易商活跃 → 看涨情绪浓厚
```

### 2.4 行情节奏

```
第一步：出口管制 → 出口锐减80%     ✅ 已完成
第二步：价格翻倍（7.5万→14.6万）   ✅ 已完成
第三步：日本企业库存耗尽 → 全球断供恐慌  ⏳ 7月即将到来
第四步：价格可能迎来第二轮大幅上涨    🔜
```

## 三、产业链竞争格局

### 3.1 全球供需数据

**供给端**：
- 2025年全球精炼铋产量约 **2.05万吨**，中国占近85%
- 2026年5月国内精炼铋产量预计环比 **-17%**
- 中国储量占全球 **75%**

**需求端**：
- 2025年全球铋消费量突破 **2万吨**
- 传统领域（低熔点合金/医药/化工催化剂）稳定
- 新兴领域（半导体封装/光伏焊带/TEC制冷）**8%-10%年均增速**

### 3.2 产业链三层

#### 上游：资源与冶炼

- 铋主要伴生于**铅锌矿、铜矿**，冶炼过程中作为副产品回收
- 主要产区：**湖南、江西、云南**
- 湖南2024年受中央环保督察进驻，原料供应一度受限

#### 中游：精炼提纯与深加工

- 国内以精铋、氧化铋等传统铋锭为主
- 高纯度铋（5N、7N）、高端铋合金、铋化合物等**高附加值产品仍落后于欧美日**
- 出口管制正在**倒逼国内企业向高附加值深加工转型**

#### 下游：TEC与光模块——全球供应链的"阿喀琉斯之踵"

| 环节 | 关键信息 |
|------|---------|
| 碲化铋 → TEC | 室温热电制冷的唯一成熟材料，短期无替代 |
| TEC → 光模块 | 800G/1.6T光模块核心温控组件 |
| 日本垄断 | 泰戈+热磁60% + 小松20% = **80%份额** |
| 断供路径 | 中国管制高纯铋出口 → 日本碲化铋原料断供 → TEC停产 → **光模块供应链断裂** |

### 3.3 铋的下游应用分布

| 应用领域 | 说明 | 增速 |
|----------|------|------|
| 低温焊料/电子封装 | 替代含铅焊料的环保方案 | 稳定 |
| 溅射靶材 | 半导体制造关键建材 | 高增 |
| **碲化铋→TEC** | **半导体制冷芯片，光模块核心** | **爆发式** |
| 医药化工 | 传统最大用途 | 稳定 |
| 光伏焊带 | 新兴应用 | 高增 |
| 第四代核反应堆 | 铅铋合金冷却剂 | 远期 |
| 相变存储器PCRAM | 高密度存储 | 研发期 |

## 四、核心壁垒

1. **资源集中度极高**：中国75%储量+85%产量，海外短期无法替代
2. **供给弹性极低**：90%+为伴生矿，无法独立扩产
3. **技术壁垒**：5N/7N高纯铋及碲化铋深加工仍由日企主导
4. **认证周期**：半导体级材料认证周期长

## 五、供需格局

```
供给：2.05万吨/年（中国85%） → 管制收紧 → 产量-17%
需求：2万吨/年 → 半导体+35% → 弱平衡已被打破
缺口：正在扩大 → 日本7月库存耗尽 → 全球断供催化
```

## 六、国产化路径

```
中国主导上游（储量75%+产量85%）
    ↓ 出口管制
精铋出口暴跌80%，海外断供
    ↓ 倒逼
国内深加工转型（5N/7N高纯铋 + 碲化铋）
    ↓ 机遇
国产TEC替代日本（泰戈/热磁/小松停产 → 国内厂商填补空缺）
    ↓ 长期
从"卖原料"升级为"卖高附加值产品"
```

## 七、标的

> [!note] 来源

### 7.1 富信科技

TEC半导体制冷芯片全产业链IDM企业，自主掌握从碲化铋晶体生长到TEC器件封装的完整工艺，国内少数能量产6N级产品并已进入光模块供应链的厂商。

### 7.2 先导基电

高端碲化铋晶体材料供应商，技术路线聚焦区熔法生长高纯单晶，纯度可达7N级别，正在加速导入800G/1.6T光模块TEC供应链。

### 7.3 有研新材

背靠有研科技集团（央企），高纯铋及铋化合物深度加工能力突出，5N/7N高纯铋产品线国内领先，出口管制背景下受益于国产深加工替代逻辑。

### 7.4 高能环境

铋资源回收龙头，从铅锌冶炼废渣及电子废弃物中回收铋等稀散金属，再生铋产能国内前列，在原生铋供应受限时再生渠道价值凸显。

### 7.5 中钨高新

钨产业链龙头（五矿集团旗下），铋作为钨冶炼伴生副产品，公司具备铋原料源头优势，出口管制强化了其资源定价权。

## 八、投资逻辑

1. **价格弹性**：铋价从7.5万→14.6万仅翻倍，距六氟化钨15倍涨幅仍有巨大空间
2. **时间催化**：7月日本TEC厂商库存耗尽 = 第二轮上涨触发点
3. **供给刚性**：伴生矿特性决定供给无法响应价格上涨
4. **需求结构变迁**：从传统医药/合金 → 半导体/光模块/核能，需求斜率陡峭
5. **国产替代窗口**：日本TEC厂商停产 = 国内碲化铋/TEC厂商的历史性机遇

## 碲化→TEC→800G光模块：被忽视的战略卡点（2026-06-28 新增）

> [!note] 来源
> 公众号「大道至简的大徒弟」《磷化铟以后一个新的卡点磷化铋，卡住了800G光模块的咽喉》（2026-06-22）

### 核心发现

800G光模块里最贵的不是芯片，而是**Micro TEC（微型半导体制冷片）**。每个800G光模块需要1~4片Micro TEC来精确控温激光芯片，温差不能超过±0.01°C。

### 碲化（Bi₂Te₃）：TEC的核心材料

- **ZT值**（热电优值）是核心指标，ZT越高制冷效率越好
- 当前量产级碲化铋ZT值可达1.3以上，其他材料在室温段远不及
- 全球高端Micro TEC市场由两家日本公司把持：

| 公司 | 全球市占 | 原料依赖 | 现状 |
|------|---------|---------|------|
| **Ferrotec（大和热磁）** | ~60% | 碲/铋95%+来自中国 | 2026年起大幅减产 |
| **KELK（小松）** | ~15-20% | 同样100%依赖中国原料 | 产能同步受限 |

### 断供时间线

| 步骤 | 时间 | 事件 |
|------|------|------|
| 第一步 | 2025年初 | 出口管制落地，碲、铋及碲化铋纳入两用物项出口管制清单 |
| 第二步 | 2025下半年起 | 审批收紧，实质减供，对日高纯5N/7N级碲原料出口许可申请基本无法获批 |
| 第三步 | **2026年起** | **产能断崖**：库存耗尽后，两家日企被迫大幅减产甚至停工 |
| 影响 | — | 全球高端Micro TEC供给缺口高达**80%**，交期从4周拉长到数月 |

### A股受益标的

#### 第一层：资源端——谁掌握铋矿

| 公司 | 代码 | 核心信息 |
|------|------|----------|
| **株冶集团** | 600961 | 国内铋冶炼龙头，年产数千吨，铋综合回收率超95%；出口管制收紧→高纯出口受限→国内铋价因需求上升而抬升→株冶量价齐升 |

#### 第二层：材料端——谁做碲化铋晶体

| 公司 | 代码 | 核心信息 |
|------|------|----------|
| **先导基电** | 600641 | 专注高纯碲化多晶/单晶材料制备，供货给下游Micro TEC器件厂；国内少数具备7N级碲化铋材料量产能力 |

#### 第三层：器件端——谁做Micro TEC（最核心）

| 公司 | 代码 | 核心信息 |
|------|------|----------|
| **富信科技** ⭐ | 688662 | A股唯一碲化铋Micro TEC全流程IDM企业，从晶体生长→切片→P/N掺杂→封装一体自研；全球仅四家具备此能力（Ferrotec、KELK、美国Marlow、富信）；前两家已断供，Marlow体量小且主攻军工，**富信是唯一能接盘的量产级替代者** |

关键数据：
- 产能：150万片/月（原100万片，持续扩产）
- 产能利用率：95%以上，满产满销
- 控温精度：±0.01°C，ZT值≥1.3
- 已验证客户：Coherent（全球光模块龙头）、华工科技、索尔思
- 2025年营收：5.35亿元

### 时间窗口判断

**核心矛盾**：需求爆发 + 日本断供 + 国内产能快速爬坡，三者在2026年同时共振。

富信科技的产能从100万片到150万片，再到未来的更大规模，每一步扩产都对应一批新客户的认证完成和订单释放。

当前时间点，认证窗口正在打开，最大的不确定性在于：海外大客户从"验证通过"到"大规模下单"的节奏，这通常是1~2个季度的时间差。
