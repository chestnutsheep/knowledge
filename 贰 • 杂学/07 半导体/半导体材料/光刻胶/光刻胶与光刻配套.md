# 光刻胶与光刻配套

## 1. 技术解构：光刻胶是什么

> [!note] 一句话理解
> 光刻胶是芯片制造中的"感光底片"——涂在硅片上，通过光罩曝光后，被光照到的地方发生化学反应，显影后形成电路图形。

### 光刻胶分类
| 类型 | 对应制程 | 国产化率 | 壁垒 |
|------|----------|----------|------|
| G线(436nm) | >500nm | >50% | 低 |
| I线(365nm) | 350-500nm | >50% | 低 |
| KrF(248nm) | 130-250nm | 20-25% | 中 |
| ArF(193nm) | 90-130nm | <5%，从0到1 | 高 |
| EUV(13.5nm) | 7nm以下 | 0% | 极高 |

### 光刻工艺全流程
```
硅片清洗 → 涂胶(光刻胶) → 软烘 → 曝光(光罩+光刻机) → 后烘 → 显影 → 硬烘 → 刻蚀/离子注入 → 去胶
```

## 2. 产业链结构

```
上游：原材料
├── 树脂(Resin)：决定胶的机械/化学性能

└── 国产：南大光电(ArF)、晶瑞电材(KrF)、上海新阳(KrF)
    ↓
下游：晶圆厂
├── 逻辑代工：中芯国际、华虹
├── 存储制造：长鑫存储、长江存储
└── 功率/模拟：士兰微、华润微
```

## 7. EUV光刻胶专题

### 7.1 技术路线：CAR vs MOR

| 维度 | 化学放大型(CAR) | 金属氧化物型(MOR) |
|------|----------------|-------------------|
| 原理 | PAG产酸→酸催化脱保护→溶解性差异 | 金属(Mo/Sn/Zr)吸收EUV光子→氧化物网络重构 |
| 灵敏度 | 中等(~30 mJ/cm2) | 高(18 mJ/cm2，金属高吸收系数) |
| 分辨率 | ~13nm极限(LER~2.5nm) | <10nm(LER可更低) |
| 抗刻蚀性 | 弱(有机体系) | 强(无机骨架) |
| 适用节点 | 3nm以上(Current EUV, NA=0.33) | High-NA EUV(NA=0.55)及以下 |
| 成熟度 | 量产主流(TOK/JSR/信越) | 中试→量产过渡(JSR MOR-101已通过2nm验证) |
| 核心瓶颈 | 随机效应(stochastic defects)→微桥/断线 | 显影后残留、环境稳定性 |
| 代表产品 | TOK CAR系列、JSR CAR系列 | JSR MOR-101(收购Inpria)、南大光电MOR体系 |

> [!warning] RLS困境
> 分辨率(Resolution)-线粗糙度(LER)-灵敏度(Sensitivity)三者不可能三角，是EUV光刻胶的"物理学天花板"。CAR体系在3nm节点已逼近极限，High-NA(0.55)必须切换MOR才能继续推进。

### 7.2 全球竞争格局：日本垄断 + 断供冲击

**日系四巨头垄断90%+高端份额（2024）：**

| 企业 | EUV份额 | 核心能力 | 客户 |
|------|---------|---------|------|
| 东京应化(TOK) | **46%** EUV独占 | 全谱系覆盖EUV/KrF全球第一，分子级光敏树脂，13nm线宽 | 台积电/三星/英特尔 |
| JSR | 16-27% | 首家EUV量产+收购Inpria(MOR)，AI分子设计 | 台积电/三星 |
| 信越化学 | ~20% | 垂直整合(硅材料→树脂→成品)，超高纯苯酚 | 台积电/三星/SK海力士 |
| 富士胶片 | 8-10% | CAR系列+电子束胶 | 存储芯片厂商 |

**2025-2026日本实质性断供时间线：**
- 2025.11：日本经产省将ArF/EUV纳入出口许可清单，审核30→90天
- 2025年底：四大日企停接中国ArF/EUV新订单，撤回驻场工程师
- 2026.02：管制清单扩至37类半导体材料
- 2026.01-05：海关数据ArF/EUV自日进口**连续归零**，整体光刻胶进口同比暴跌80-90%
- 2026.06.22：四家企业同日统一行动，高端断供坐实

> [!danger] 保质期陷阱
> 光刻胶保质期仅3-6个月，无法囤货。EUV光刻胶95%产能被日本控制，国内暂无量产替代。断供=先进制程停摆。

### 7.3 国产EUV突围路径

| 玩家 | 路线 | 进展 | 关键指标 |
|------|------|------|---------|
| 南大光电 | MOR(金属氧化物) | 国内首条EUV中试线，投入3.21亿 | 月产能50吨试产 |
| 北京科华/彤程新材 | CAR(化学放大) | 投入2.94亿，配方优化+稳定性提升 | 验证周期缩短至6个月 |
| 晶瑞电材 | MOx(金属氧化物) | 中芯国际产线首轮测试 | 灵敏度18mJ/cm2，接近ASML推荐参数 |
| 上海新阳+科华 | MOR | 联合开发，初步流片测试 | 分辨率达13nm以下 |
| 清华大学 | 聚碲氧烷路线 | 实验室突破 | 下一代方向，碲为核心吸收元素 |
| 徐州博康 | CAR/MOR | 首轮客户测试 | 灵敏度/分辨率接近TOK同类 |

**中国反制筹码——碲(Te)：**
- 碲是下一代EUV光刻胶(MOR)的核心吸收元素
- 全球碲产能主要在中国
- 中国已对碲实施出口许可制度
- 形成"日本卡光刻胶 ↔ 中国卡碲"的双向制衡

### 7.4 EUV光刻胶市场规模

- 2025年全球EUV光刻胶市场：**24.8亿美元**

## 8. 投资逻辑

> [!tip] 核心逻辑
> 1. **断供加速国产替代**：日本ArF/EUV断供是结构性事件，不是短期扰动。晶圆厂被迫开放产线认证，国产验证周期缩短30%+
> 2. **KrF先放量，ArF弹性最大**：KrF已30%国产化，订单爆发确定；ArF国产化率<1%，南大光电是唯一量产标的
> 3. **EUV是长期期权**：国内仍在中试/实验室阶段，但方向明确(MOR)，3-5年维度看可能打破垄断
> 4. **上游材料是隐藏主线**：光刻胶树脂、PAG光酸、高纯溶剂、特种单体——这些"卡脖子中的卡脖子"正在同步突破
> 5. **碲/稀有金属反制**：中国控制碲/镓/锗等光刻胶上游关键原料，形成双向制衡
