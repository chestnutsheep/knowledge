# 军工产业链：战斗机/导弹/航空航天核心20+上市公司

> [!note] 来源：公众号「原点参数产业链分析」《战斗机导弹整机+航空航天零部件+高温特种材料，军工产业链核心20+上市公司》（2026-06-20）

## 一、产业拆解逻辑

完整军工产业链路径：**宇航特种矿产 → 高温特种材料 → 精密成型零部件 → 载机/制导分系统 → 战斗机/导弹/卫星整机**

1. **高温材料**（产业链最上游根基）：高温合金、宇航钛、碳纤维、特种陶瓷、军工稀土永磁。承受上千度高温、强辐射，是航发、导弹、卫星基础骨架，整机成本占比超30%，国产化核心攻坚环节。
2. **航空航天零部件**（中游高壁垒环节）：航发盘轴叶片、机载连接器、导弹导引头、火箭阀门、卫星结构钢件，装备"心脏、神经、大脑"，细分技术壁垒最高，卡脖子重灾区。
3. **战斗机/导弹/卫星整机**（下游终端）：歼击机、运输机、直升机、防空/反舰导弹、运载火箭、低轨卫星总装，产业链价值最终释放端，订单体量最大。

## 四、文末总结

1. **打通高温材料+航空零部件+整机三段一体化企业**：航发动力、中航重机、中航高科；内部配套消化原料波动，客户资源复用，经营韧性最强。
2. **主营上游高温特种材料，不做零部件、整机**：抚顺特钢、宝钛股份、钢研高纳、中简科技、西部超导；全行业刚需原料供应商，整机扩产直接受益，不受装备交付周期拖累。
3. **主营航空航天零部件，无整机总装产能**：中航光电、航发控制、航发科技、航天电器、高德红外；细分技术壁垒高，绑定头部整机厂，业绩确定性强。
4. **专注战斗机/导弹/卫星整机，材料零部件全部外购**：中航沈飞、中航电测、中航西飞、洪都航空、中兵红箭、中国卫星；下游国防刚需直接受益，但原材料涨价会直接挤压整机利润。
