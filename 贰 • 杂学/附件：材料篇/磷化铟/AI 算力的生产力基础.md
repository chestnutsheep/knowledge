> Token 是 AI 模型处理的最小单元，每一次推理或训练都消耗大量 Token。Token 需求直接驱动底层算力投资。

## 2. 从 Token 到 XPU

- 每 1M Token 的推理成本 ≈ $0.1–0.5（取决于模型）
- 算力投资 = Token 需求 × 单位算力成本
- 每一美元算力支出 → 拉动产业链上每一个环节（互联、光模块、半导体）
