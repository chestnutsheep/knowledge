# 政策与行业动态

> [!important] 核心判断
> 2026年7月是中药政策历史上最密集的落地窗口期。三重政策同步发力（十五五规划+基药目录+说明书整改），不是短期题材炒作，而是五年长周期红利的起点。

---

## 一、2026年7月三重政策落地

### 1. 十五五规划批复

| 要素 | 内容 |
|------|------|
| **文号** | 国函〔2026〕71号 |
| **发布** | 国务院（2026.07.10挂网公布） |
| **全称** | 《中医药振兴发展"十五五"规划》 |
| **周期** | 2026-2030年（五年长周期） |
| **定位** | 国务院批复的专项规划（高于部门指导意见） |

**核心要求**：
- 各省市将中医药产业振兴纳入本地十五五重点考核任务
- 坚持中西医并重，守正创新
- 完善中医药传承创新发展机制
- 加快推进中医药现代化
- 推动中医药走向世界

**配套产业目标**：
- 配套专项资金、专项扶持项目、产业补贴全部到位
- 覆盖全产业链：道地药材基地 → 智能工厂 → 创新药研发 → 基层中医康养 → 国际化出海

**八部门联合方案**（工信部等）：

| 目标 | 2030年 |
|------|--------|
| 标准化道地药材基地 | 60个 |
| 中药智能化生产工厂 | 20座 |
| 数字化升级 | 全面推动 |

> [!note] 与十四五的区别
> 十五五规划从**部门规划**升级为**国务院批复专项规划**，政策执行力和资源保障力度显著增强。要求各地"确保规划目标任务和政策措施落到实处"，意味着有刚性约束。

### 2. 新版基药目录

| 要素 | 内容 |
|------|------|
| **文件** | 《国家基本药物目录（2026版）》 |
| **发布** | 国家卫健委+国家中医药局+国家疾控局（2026.07.09） |
| **施行** | 2026.09.01 |
| **距上次更新** | 8年（上一版2018年） |

#### 目录结构

| 类别 | 数量 | 占比 |
|------|------|------|
| **药品总量** | 794种 | — |
| 化药生物药 | 476种 | 60% |
| **中成药** | **318种** | **40%** |
| 较2018版新增 | 116种 | — |
| 其中中成药新增 | **48种** | — |
| 调出 | 2种 | — |

#### 中成药新增详情

| 维度 | 数据 |
|------|------|
| 新增品种 | 48个 |
| 独家（专利）品种 | 37个（占比77%） |
| 独家剂型 | 6个 |
| 新增中药创新药 | 16种（含1种中成药：解郁除烦） |
| 新增国产I类新药 | 4种（含解郁除烦） |
| 新增剂型 | 10个品种 |
| 调出品种 | **0个** |
| 调出剂型 | 3个（安神片、六味地黄颗粒、脑心通片） |

#### 新增品种聚焦领域

- 心系用药5种
- 肺系用药4种
- 脑系用药4种
- 妇科用药4种
- 儿科专用药3种
- 新增品种包含：康复新液、小儿豉翘清热、肺力咳、黄葵等大品种
- 创新品种：解郁除烦、芍麻止痉等

#### "986"备药率考核

| 医院等级 | 基本药物配备比例 |
|----------|----------------|
| 一级 | ≥90% |
| 二级 | ≥80% |
| 三级 | ≥60% |

> [!important] 基药扩容的核心意义
> 基药目录是全国公立医院**强制采购清单**。纳入目录 = 院端长期稳定增量。华泰证券复盘：中小品种进入后3-5年收入有望翻倍以上。

#### 两大突破性定位

1. **支持创新药**：首次将创新药纳入基药遴选范围，"基药不只保基本、也要纳创新"
2. **中西药并重**：中成药占比提升至40%，新增藏药、蒙药、维药等少数民族药品

### 3. 中成药说明书整改大限

| 要素 | 内容 |
|------|------|
| **生效** | 2026.07.01 |
| **核心** | 再注册审核中，不良反应/禁忌仍标注"尚不明确"的品种，**不予通过** |
| **配套** | 黄芪类中成药转OTC、中药饮片全链条溯源国标强制推行 |

**影响**：
- 中小落后产能加速出清
- 合规头部企业市场份额提升
- 行业准入门槛大幅抬高
- 推动说明书规范化，增强消费者用药安全意识

## 四、审评审批改革核心进展

### "三结合"体系

> [!note] 中药审评的革命性变化
> 构建"中医药理论 + 人用经验 + 临床试验"相结合的中药注册审评证据体系，这是中药区别于化药的根本制度创新。

**2025年关键成果**：
- 制定《中药复方制剂新药研发人用经验收集整理技术指导原则（试行）》
- 发布《中药改良型新药研究技术指导原则（试行）》
- 16个古代经典名方中药新药获批
- 2个中药改良型新药获批
- 10余个品种基于中医药理论+人用经验无需开展药效学试验
- 2个中药复方制剂基于人用经验直接开展确证性临床试验
- 每年获批中药新药10个以上

### 中药注册数据全景（2025年）

| 类别 | 受理 | 审结/批准 |
|------|------|----------|
| 临床试验申请 | 140件 | 115件（102个品种） |
| NDA（上市申请） | 54件 | 39件 |
| 补充申请 | 2488件 | 2246件 |
| **合计** | **2723件** | **2439件** |

其中NDA批准细分：
- 创新中药NDA：5件（5个品种）
- 改良型中药NDA：3件（3个品种）
- 经典名方NDA：16件（16个品种）

## 六、国际化政策推动

- 十五五规划明确"推动中医药走向世界"
- 2025年中药产品出口78.2亿美元（同比+16.4%）
- 38个中成药在海外正式获批上市，12个进入当地国家医保
- 2025年新增《中医药临床研究质量控制规范》首个国家标准，为国际接轨奠定基础
- 中医诊断术语标准化（舌象、脉象等），推动中医药表达转化为现代科学认可的数据表达

## 九、政策风险与不确定性

1. **政策落地不及预期**：地方配套资金和执行力度可能滞后
2. **中成药集采扩面**：独家品种虽暂不受影响，但政策风险需关注
3. **基药入院进度**：品种进入目录后实际放量可能慢于预期
4. **说明书整改冲击**：部分中小品种可能因整改退出市场
5. **国际地缘风险**：中药材出口可能受到贸易摩擦影响
