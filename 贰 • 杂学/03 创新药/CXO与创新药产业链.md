## 1.1 创新药类型与技术路线

|类型| 类型 | 特征 | 代表企业 |
|------|------|----------|

| 大分子药物 | 蛋白/抗体，结构复杂，需活细胞培养 | [[百济神州]]、[[信达生物]]、[[君实生物]]、迈威生物 |

| 小核酸药物 | 在基因源头阻断致病蛋白产生 | 瑞博生物、悦康药业、[[恒瑞医药]]、康诺亚 |
| 细胞/基因治疗 | 改造身体自身的细胞和基因 | 传奇生物、驯鹿生物、科济药业、尧唐生物 |

五、行业趋势与观察变量

5.1 政策端

2026年《政府工作报告》将生物医药列为 "新兴支柱产业"
2026.6.29 国家医保局公示2026年药品目录初审名单：557个药品通过，其中五年内获批新药343个
创新药指数PS估值处于2019年以来37%分位

5.2 产业趋势

产业分层加剧：头部集中化，尾部加速出清
头部：全球临床能力 + 差异化技术平台 + 丰富管线 → 持续拿大额BD订单
尾部：纯me-too / 无差异化 / 缺乏全球布局 → 国内医保内卷 + 出海无门
技术方向引导：ADC、双抗/多抗、GLP-1、siRNA、自免、核药为核心方向
全产业链协同：CXO与配套（生物试剂/高端设备/临床研究服务）直接受益
5.3 三大观察变量

📋 来源：「CRO专题研究」
创新药回暖持续性：医保准入 + License-out双引擎能否持续？→ 决定CRO订单增速能否维持20%+
GLP-1全球放量持续性：司美格鲁肽需求 vs 产能扩张 → 决定多肽CDMO量价走势
