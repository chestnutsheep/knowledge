# 贰 • 杂学 · 双维度检索索引

> **设计目的**：用 Dataview 同时支持「按部件」和「按原材料」两个维度检索笔记。
> 文件夹只表达行业大类；部件/原材料维度全部由 frontmatter 字段承担。
> 新增笔记只要补全 `Component` 和 `Raw-Material` 字段，下面三张表会自动收录。

---

## 维度一：按原材料检索

每个原材料平铺出所有涉及它的笔记（跨子分类聚合，「铋」会同时出现在半导体/军工等）。

```dataview
TABLE Component AS 部件, Area AS 行业, Confidence AS 可信度
FROM "贰 • 杂学"
FLATTEN Raw-Material AS 原材料
WHERE 原材料
SORT 原材料, file.name
```

---

## 维度二：按部件检索

每个部件平铺出所有相关笔记。

```dataview
TABLE Raw-Material AS 原材料, Area AS 行业, Confidence AS 可信度
FROM "贰 • 杂学"
FLATTEN Component AS 部件
WHERE 部件
SORT 部件, file.name
```

---

## 全量笔记清单（含双维度字段）

```dataview
TABLE Component AS 部件, Raw-Material AS 原材料, Confidence AS 可信度, Data-Timestamp AS 更新
FROM "贰 • 杂学"
SORT file.folder, file.name
```

---

## 使用说明

- 想加一个原材料维度：在笔记 frontmatter 的 `Raw-Material:` 下加 `- 某材料`。
- 想加一个部件维度：在 `Component:` 下加 `- 某部件`。
- 两个字段必须是数组（`- 值` 形式），否则检索匹配会失效。
- 模板见 [[玖 • 模版/标准笔记模板]]。
