# 前端工程师 15 个 AI Skill（设计到交付链路）

> 来源：IMA 知识库微信文章（公众号「大前端架构师」Kryon）。从过去 30 天挑出 15 个真正服务前端日常工作流（设计、编码、验收、交付）的 Skill，建议优先装顺核心链路而非盲目堆积。

## 设计阶段
- frontend-design：视觉方向/排版/配色/动效/响应式纳入提示框架。
- web-design-guidelines：偏界面规范的 Web 设计检查表（间距/层级/交互/可访问性）。
- extract-design-system：从现有代码抽 token/组件/模式，接手成熟项目或补设计系统文档。
- ui-ux-pro-max：复杂界面与交互层 UI/UX 方案（后台/工作台/多状态页）。
- high-end-visual-design：高级感/编辑感/品牌质感（着陆页/品牌页）。
- canvas-design：画布环境快速迭代视觉方案、结构草图、探路。

## 编码阶段
- vercel-react-best-practices：React/Next.js 性能与结构规则，减少重渲染/大包体。
- shadcn：让 agent 懂 shadcn/ui 安装/组合/主题/定制。
- vercel-composition-patterns：React 组件 API 组合，治理 boolean props 泛滥。
- next-best-practices：约束 Next.js App Router/RSC 边界/元数据/异步模式。
- design-taste-frontend / emil-design-eng：视觉判断与设计工程打磨，提升精致度。

## 验收 / 交付
- agent-browser：真实浏览器操作接入 agent，页面验证/录制/回归留证。
- webapp-testing：单元/集成/端到端测试思路，定义「什么叫测到了」。
- playwright-cli：Playwright CLI 变 agent 可驱动浏览器工具，录制/检查/复现。
