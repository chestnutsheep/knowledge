# 产业链 Canvas 模板（使用说明）

配套文件 `产业链Canvas模板.canvas` 是一份可直接复制重命名的 Obsidian Canvas 骨架。Canvas 用于把"上游原材料 → 功能材料 → 下游组件 → 终端场景"的产业链以可视化节点 + 连线呈现，并挂载关联研报。

## 布局约定
- **横向从左到右** = 产业链上游 → 下游（原材料 / 功能材料 / 组件 / 场景）。
- **颜色分层**：`1` 上游、`2` 功能材料、`3` 组件、`4` 场景、`6` 研报/资料。
- **节点类型**：
  - `type:"text"`：放概念名 + `[[双向链接]]`，点击即可跳转到对应概念卡。
  - `type:"file"`：直接嵌入某篇研报/笔记（形如 `"file":"肆 • 机构观点/标题.md"`）。
- **连线 `edges`**：`fromSide`/`toSide` 用 `left/right/top/bottom` 控制箭头方向，体现传导关系。

## 使用方法
1. 复制 `产业链Canvas模板.canvas` 为 `产业链Canvas-行业名.canvas`。
2. 把节点文本里的 `[[原材料概念卡]]` 等替换为真实概念卡名（保持 `[[ ]]` 以保留跳转）。
3. 在研报节点填入该行业相关研报标题（`[[标题]]`）。
4. 从行业 MOC 用 `[[产业链Canvas-行业名]]` 引用本图，形成"总览页 → 可视化"闭环。

## 维护要点
- Canvas 中的 `[[链接]]` 同样计入全库双向链接，重命名概念卡/研报时需同步刷新（已验证重命名脚本不覆盖 `.canvas` 内的链接，需手动或另行脚本更新）。
- 节点坐标 `x/y` 仅影响布局，不影响语义。
